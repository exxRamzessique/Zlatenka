# 💗 Любовь к Златеньке — сайт-подарок

Романтический лендинг: сердце из причин любви, «Дорога нашей любви» с шестью
личными остановками (переписка, признание, фото), письмо, счётчик дней
вместе, музыкальный плеер, генератор комплиментов и секрет в углу экрана.

## Файлы проекта

```
index.html       — структура страницы
style.css        — оформление и анимации
script.js        — вся интерактивность и личный текст (см. ниже)
README.md        — этот файл
PROJECT_MAP.md   — техническая карта проекта (для правок, не обязателен для деплоя)
audio/
  our-song.mp3   — трек плеера («Мало тебя» — SEREBRO)
images/
  couple.png         — иллюстрация пары (остановка «Далее»)
  bunny.png          — фото игрушки (остановка «Пополнение»)
  cinema.png         — фото (остановка «Приключение»)
  firstmeet.png      — фото (остановка «Первая встреча»)
  angel-nebula.jpg   — фото NASA APOD (бонус в окне «Признание»)
```

Файл `preview.html`, если он у вас есть — служебный, только для предпросмотра
в чате с Claude. Для деплоя он не нужен, в репозиторий его добавлять не надо
(он и так исключён через `.gitignore`).

## Структура сайта

1. **Hero** — заголовок и признание, плавающие сердечки на фоне
2. **Причины** — 41 плитка-причина, собираются в сердце при прокрутке
3. **Дорога нашей любви** — извилистый путь с 6 остановками:
   первый разговор (переписка), признание (письмо), первая встреча (фото + текст),
   пополнение / приключение / далее (фото)
4. **Счётчик** — дни/часы/минуты/секунды вместе
5. **Наша песня** — кнопка + выезжающая панель плеера
6. **Письмо** — конверт → письмо
7. **Комплименты** — генератор случайных комплиментов
8. Футер + секретное сердечко в углу экрана

## Как персонализировать дальше

1. **Дата начала отношений** — `script.js`, переменная `const startDate = new Date('2026-05-19T05:39:00');`.
2. **Причины** — `script.js`, массив `const reasons = [...]` (41 строка, редактируется свободно).
3. **Остановки дороги** — `script.js`, массив `const ROAD_STOPS = [...]`: у каждой остановки
   `title`, `caption`, текст (`chat`/`paragraphs`/`heading`) и `photo` — путь к файлу в `images/`.
   Координаты (`left`/`top`, в %) привязаны к форме дороги — SVG-путь (`d=`) лежит в `index.html`
   в секции `#gallery`; если меняете форму пути, координаты остановок надо пересчитать.
4. **Комплименты** — `script.js`, массив `const compliments = [...]`.
5. **Письмо** — `index.html`, секция `<section id="letter">`.
6. **Музыка** — замените `audio/our-song.mp3` на свой файл с тем же именем,
   либо поменяйте путь в `<audio id="songAudio" src="...">` в `index.html`.
7. **Секретное послание** — `index.html`, блок `id="secretMessage"`.

> Некоторые фразы написаны от мужского лица («благодарен», «твой»). Если нужно —
> замените на женские окончания через поиск по файлу.

## Подготовка к загрузке (Git)

Если Git ещё не установлен локально — скачайте с [git-scm.com](https://git-scm.com/).
Дальше действия одинаковые что для GitHub Pages, что для Vercel:

```bash
cd путь/к/папке/с/проектом
git init
git add index.html style.css script.js README.md .gitignore images audio
git commit -m "Любовь к Златеньке — сайт"
```

(Если хотите — добавьте и `PROJECT_MAP.md`, он не обязателен, но не мешает.)

## Деплой на GitHub Pages

1. Создайте новый репозиторий на [github.com](https://github.com/new) (например, `zlatenka`), **не** отмечая
   «Add a README» (у вас уже есть свой).
2. Свяжите локальную папку с репозиторием и отправьте файлы:
   ```bash
   git branch -M main
   git remote add origin https://github.com/ваш-логин/zlatenka.git
   git push -u origin main
   ```
   (Ссылку `https://github.com/...` возьмите со страницы репозитория — кнопка **Code**.)
3. В репозитории на GitHub откройте **Settings → Pages**.
4. В разделе **Build and deployment → Source** выберите **Deploy from a branch**,
   ветку **main**, папку **/ (root)** → **Save**.
5. Через 1–2 минуты сайт появится по адресу:
   `https://ваш-логин.github.io/zlatenka/`

Обновления после этого — просто `git add . && git commit -m "правки" && git push`,
сайт пересоберётся сам за минуту-две.

## Деплой на Vercel

### Способ А — через GitHub (проще всего, если уже сделали шаги выше)

1. Зайдите на [vercel.com](https://vercel.com) и войдите через свой GitHub-аккаунт.
2. **Add New → Project**, выберите репозиторий `zlatenka` из списка.
3. Framework Preset — оставьте **Other** (это статический сайт, без сборки).
   Build Command и Output Directory можно оставить пустыми.
4. Нажмите **Deploy**. Через минуту сайт будет доступен по адресу вида
   `https://zlatenka.vercel.app` (Vercel предложит поменять имя проекта, если хотите).
5. Дальше при каждом `git push` в `main` Vercel будет пересобирать сайт автоматически.

### Способ Б — без GitHub, напрямую с компьютера (Vercel CLI)

1. Установите Node.js, если его нет: [nodejs.org](https://nodejs.org).
2. В терминале, в папке проекта:
   ```bash
   npm install -g vercel
   vercel login
   vercel
   ```
3. На вопросы CLI отвечайте по умолчанию (Enter): *Set up and deploy* → yes,
   *link to existing project* → no, имя проекта — любое, *directory* — `.` (текущая папка),
   *override settings* → no.
4. Через минуту CLI выдаст ссылку на сайт (`https://....vercel.app`). Для повторного
   деплоя после правок — просто снова `vercel` (или `vercel --prod` для продакшн-адреса).
